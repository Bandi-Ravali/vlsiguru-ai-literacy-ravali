## Notes

### What did the AI get right?
The AI tools were helpful in explaining the main concepts and generating simple examples. Most of the answers were consistent with the information from reliable or official sources.

### What did it get wrong or leave unsupported?
During the hallucination experiment, the two AI tools gave different answers about Python `list.sort()`. The Python documentation confirmed that `list.sort()` returns `None`, so the Gemini answer was incorrect.

### What did I learn about verification?
I learned that AI answers should not always be accepted directly. For important technical information, I should check the answer using reliable or official sources and compare the evidence before using it.
