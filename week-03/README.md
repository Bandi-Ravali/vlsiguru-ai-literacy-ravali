## 1. Purpose

The purpose of Week 03 is to learn how AI tools can support engineering learning, how to write better prompts, how to compare AI-generated answers, and how to investigate an open-source tool relevant to Physical Design.

AI can help explain concepts, suggest examples, and support research. However, an AI-generated answer is not automatically correct. Important technical claims must be checked against reliable sources, and code or commands should be tested before relying on them.

## 4. Key Learning Principles

1. Ask clear questions and provide enough context.
2. Request explanations that match my current knowledge level.
3. Verify important technical claims using reliable sources.
4. Try small examples where possible and record actual results.
5. Explain concepts in my own words.
6. Never upload confidential RTL, netlists, timing constraints, chip data, credentials, or proprietary company information to public AI services.
