## Overview

This repository contains my Week 04 assessment on **Deep Learning** as part of the VLSIGuru AI Literacy Layer programme.

In this assessment, I explored the fundamentals of deep learning, the differences between Machine Learning and Deep Learning, neural network architecture, how neural networks learn from data, and practical experimentation using an online neural network playground.

The purpose of these missions is to develop a foundational understanding of deep learning and explore its potential applications in engineering.

## Learning Objectives

- Understand the fundamentals of Deep Learning.
- Differentiate Machine Learning from Deep Learning.
- Understand the structure and components of neural networks.
- Learn how neural networks learn from data.
- Experiment with neural network settings and observe their effects.
- Explore the applications of AI in engineering.
- Develop critical thinking and independent learning skills.
- Refer to reliable sources to strengthen technical understanding.

## Missions

### Mission 1: The Data Behind Deep Learning

Explored the importance of data in deep learning and how models learn patterns from examples to make predictions.

**Key learning:** Data quality, quantity, and relevance can influence how well a model learns and performs.

### Mission 2: Machine Learning vs. Deep Learning

Studied the relationship between Machine Learning and Deep Learning, including their approaches to learning from data and solving problems.

**Key learning:** Deep Learning is a branch of Machine Learning that uses neural networks with multiple layers to learn complex patterns.

### Mission 3: Neural Network Diagram

Explored the basic architecture of a neural network, including input layers, hidden layers, output layers, neurons, and connections.

**Key learning:** Each layer processes information and passes it to the next layer to help generate an output.

### Mission 4: How Neural Networks Learn

Studied how neural networks learn by comparing predictions with expected outputs and adjusting internal parameters during training.

**Key learning:** Training methods such as backpropagation and gradient-based optimization help neural networks reduce prediction errors.

### Mission 5: Neural Network Playground Experiment

Explored TensorFlow Playground to observe how neural network settings affect learning and decision boundaries.

**Key learning:** Changes to network structure, activation functions, and other settings can influence the model's learning behavior.

### Final Challenge: Engineering Case Study

Explored how AI and deep learning can be applied to engineering problems involving data analysis, pattern recognition, classification, and prediction.

**Key learning:** AI can support engineering decisions, but the quality of the data and validation of model predictions are important.

### Final Reflection

Reflected on the concepts learned throughout the Week 04 missions and the value of combining theoretical understanding with practical experimentation.

**Key learning:** Hands-on exploration and reliable learning resources help build a stronger foundation in AI and Deep Learning.

## Key Takeaways

- Data is an essential part of training deep learning models.
- Machine Learning and Deep Learning are related but have different approaches.
- Neural networks consist of interconnected layers that process information.
- Neural networks learn by adjusting their parameters during training.
- Experiments help demonstrate how network settings influence learning.
- Deep learning has potential applications across engineering fields.
- Model outputs should be evaluated rather than accepted without verification.
